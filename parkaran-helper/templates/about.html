Sources and judgment

What the system knows, and what it suggests.

Preserved Gurbani

The local BaniDB snapshot supplies Gurbani, translations, transliteration, writer, raag and ang. Search normalization changes only search keys. Displayed scripture stays intact.

{{ concept_count }} curated concepts

Concept definitions were curated and confirmed by Ujjal. Assignments are a separate layer: lexical tags record configured word matches; inferred tags use English-translation similarity. Read the cited verse in context.

Evidence before counts

Lexical matches are preserved. Inferred connections use a threshold for each concept, without a quota on how often it may occur. These suggestions remain open to review in their full shabad.

Your interpretation

Connections, summaries and inferred assignments can be wrong. Description-only topics have no configured lexical anchors. Ranking indicates where to look; your reading determines whether a connection belongs in the parkaran.

Local by design.

The core explorer uses local data, fonts, scripts and search models. Your saved sets live in browser storage and do not sync between devices automatically. This is a responsive web app; native installation is separate work.
